## Objetivo

Mostrar a reclutadores y a dueños de negocios los sistemas que he construido, con el sistema de carga y encomiendas de AYBIZ Cargo Express como caso de estudio principal.

## Páginas

1. `index.html` — Inicio
2. `proyectos.html` — Proyectos
3. `caso-aybiz.html` — Caso de estudio: sistema de carga y encomiendas AYBIZ
4. `como-trabajo.html` — Cómo trabajo
5. `contacto.html` — Contacto

## Alcance técnico

- Parcial: HTML5 semántico de las cinco páginas, con imágenes reales del sistema.
- Final: CSS, Flexbox/Grid, Bootstrap, diseño adaptable y accesibilidad.
- Publicación: GitHub Pages.
- Fuera de alcance: login, pagos, base de datos y envío real del formulario.
